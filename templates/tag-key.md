# Tag Key

Copy inside the notebook's front cover.

## Error tags (one per moment)

| Tag | Meaning |
| --- | --- |
| H | Hung a piece: moved to or left a piece where it could be taken for free |
| M | Missed opponent's threat: didn't check their checks, captures and threats |
| T | Missed my own tactic or free material |
| K | King safety or mate: back rank, exposed king |
| C | Clock: rushed the critical move, or got into time trouble |
| O | Opening principle broken: lost material or development early |
| E | Endgame: failed to convert a winning position |

## Engine marks

| Mark | Meaning |
| --- | --- |
| ✓ | I found this moment myself before turning the engine on |
| ✗ | Only the engine found it |

## Maia classes (weekly Maia session only)

| Class | Meaning | Fix |
| --- | --- | --- |
| N | Next level: players ~300 above me usually find the right move | Study the pattern; replay the position |
| L | Later: only players 300–800 above me find it | Note it, don't drill |
| X | Hard: rare even near 2000+ | Skip |
| R | Random lapse: players at my level usually find it | Process: blunder check, clock |
